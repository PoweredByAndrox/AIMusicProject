# lyrics-worker

Локальный сервис для текста песни по вокальному stem'у.

## Что делает

- `transcribe_wordlevel` — WhisperX word-level transcription с таймкодами.
- `align_reference_lyrics` — stable-ts forced alignment для заранее известных правильных lyrics.

## Почему две стадии

1. **WhisperX** быстро делает автоматическую транскрипцию с пословными таймкодами.
2. **stable-ts** позволяет выровнять **уже правильный текст** по аудио, если тебе нужен максимально близкий к `1-в-1` результат.

## Практика

Если нужна просто автоматическая черновая транскрипция:
- запускай `transcribe_wordlevel`

Если нужен максимально точный текст и у тебя уже есть lyrics в `.txt` / `.lrc`:
- запускай `align_reference_lyrics`
- передавай `lyrics_reference_path`
- лучше использовать уже выделенный `vocals` stem, а не полный микс

## Ограничение

ASR по пению не гарантирует идеальный текст сам по себе. Для наиболее точного `1-в-1` текста нужен либо reference lyrics, либо ручная проверка после авто-выравнивания.
